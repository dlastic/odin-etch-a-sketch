# Etch-a-Sketch  

This is an interactive Etch-a-Sketch project, built as part of the Odin Project curriculum. Users can draw on a grid by hovering over the squares while holding the mouse button or just by clicking the mouse button over the square. The grid size can be adjusted, the square color can be changed, and a rainbow mode for random square coloring is available.  

The project focuses on JavaScript event handling, DOM manipulation, CSS styling, and user interaction.  

## How to Use  

1. Open the `index.html` file in your browser.  
2. Move the mouse over the grid while holding the mouse button to draw (Clicking the mouse over the grid works as well).  
3. Click "Grid Size" to adjust the number of squares per side.  
4. Click "Change Color" to select a custom color.  
5. Toggle "Rainbow Mode" for multi-colored drawing.  
6. Click "Clear" to reset the grid.  

Enjoy drawing!
